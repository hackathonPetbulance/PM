# 01_SideProject_AndroidApp – 안드로이드 앱 사이드 프로젝트

이 폴더는 부트캠프 종료 후,  
외부 **개발자 & 디자이너를 모집해 진행한 안드로이드 앱 사이드 프로젝트** 단계의 문서를 모아둔 공간입니다.

> “아이디어에서 벗어나, 실제로 출시 가능한 앱으로 옮겨가기 시작한 단계”

---

## 🧭 이 단계의 맥락

- 시점: 부트캠프 종료 이후, **개인/팀 사이드 프로젝트로 확장**
- 구성:
  - 외부 **Android 개발자, 디자이너**와 함께 실제 앱 구조를 설계
- 주요 기능(**AI 기능 미도입**):
  - 특수동물 **병원 검색 기능**
  - **영수증 후기** 기반 정보 공유
  - 특수동물 보호자 **커뮤니티(게시판)** 기능

> 이 단계에서 펫뷸런스는  
> “AI 서비스”가 아니라 **특수동물 병원 정보 & 커뮤니티 플랫폼**으로 정의됩니다.

---

## 📂 이 폴더에 담긴 주요 문서 

- `01_01_안드로이드앱_기능정의서_v1.pdf`  
  → 전체 앱 구조, 주요 기능 리스트, 화면 흐름 개요

- `01_04_안드로이드앱_병원검색_기능정책.pdf`  
  → 병원 검색/필터링/정렬 로직 및 예외 케이스 정책

- `01_06_안드로이드앱_영수증후기_기능정책.pdf`  
  → 진료 영수증 기반 후기 작성, 검증, 노출 정책

- `01_07_안드로이드앱_커뮤니티_기능정책.pdf`  
  → 게시판 구조, 카테고리, 신고/차단 등 커뮤니티 운영 정책

- `00_02_안드로이드앱_개인정보처리방침_초안.pdf`  
  → 앱 출시를 대비한 개인정보·민감정보 처리 기준 초안

## 🔗 이 단계의 의미

- 부트캠프에서 나온 **아이디어를 실제 서비스 구조로 구체화**한 단계
- 이후 **SeSAC AI 해커톤에서 AI 기능(MVP)**을 올릴 수 있었던  
  **“베이스 앱 구조”**가 정리된 시기
- “AI가 없어도 돌아가는 펫뷸런스 베이스 서비스”의 정의를 담고 있음
