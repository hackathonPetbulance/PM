# 📂 DOCS – Planning & Documentation

이 폴더는 **프로젝트 기획 단계에서 고민한 모든 문서와 산출물**을 모아두는 공간입니다.  
서비스의 방향, 문제 정의, 정책, 플로우 등이 어떻게 만들어졌는지 추적할 수 있는 **기록 보관소(Archive)** 역할을 합니다.

---

## 📁 포함되는 문서 유형

- 서비스 기획서 / 아이디어 정리 문서
- 문제 정의서, 타겟 사용자 · 페르소나 정리
- 요구사항 정의서(Requirements)
- 기능별 정책 문서 및 플로우(Flow Chart, Use Case 등)
- UX 리서치 메모, 인터뷰/설문 결과 요약
- 해커톤/발표용 스크립트 초안 및 회고 문서 등

> 코드가 아닌 **생각과 결정의 흔적**은 모두 DOCS 폴더에 정리합니다.

---

## 🧾 파일/폴더 버전 가이드 (권장)
- 버전이 나뉘는 경우: `v1`, `v2` 등의 suffix 사용  
  - 예) `20251202_기획안_펫뷸런스_v1.md`

---

## 🔄 업데이트 원칙

- **최신본(New)** 은 기존 파일을 무조건 덮어쓰기보다는  
  - 변경 이유가 큰 경우: 새 파일로 `v2`, `v3` 형태로 추가  
  - 오탈자/작은 수정: 기존 파일 수정 후 커밋 메시지에 수정 내용을 간단히 기재
- 기획/정책에 중요한 결정이 생기면,  
  - 관련 문서를 여기에 추가하고  
  - 필요 시 README에 간단히 링크를 남겨 추적 가능하게 합니다.
